Projects

Rolling LED Display

Designed and developed a 6×24 LED matrix display capable of showing dynamic scrolling messages. The system integrates brightness and temperature sensors to automatically adjust display behavior based on ambient conditions. The project required both hardware integration and software logic to control the LED matrix and sensor inputs.

D'Arsonval Multimeter

Built a functional multimeter using a D'Arsonval movement meter and precision resistors. The project applied key electrical engineering principles including Ohm's Law, Kirchhoff's Voltage Law (KVL), and Kirchhoff's Current Law (KCL). A custom PCB was designed to integrate the measurement circuitry, and a CubeSat-inspired enclosure was modeled in SolidWorks and fabricated.

Line Following Robot

Developed a line-following robot controlled by a 16-bit microcontroller programmed in C. The robot used photoresistors to detect the track line and adjust motor control in real time. Motor actuation was implemented using a high-current half-H driver capable of supporting bidirectional drive currents.
